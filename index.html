About

I'm a Computer Science student who likes understanding systems from both sides — how to build them well, and how they get taken apart. That's what pulled me into a cybersecurity minor alongside my CS coursework: writing software is more interesting when you're also thinking about where it can fail.

Most of my hands-on experience so far is in Java — building a desktop application from login screens down to Maven build issues — plus lower-level work in Assembly and controlled security exercises in Kali Linux. I'm comfortable moving between frontend interfaces and backend logic, and I like projects that force me to debug something unfamiliar.
